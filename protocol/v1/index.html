How the document runs

Protocol

A signed revision carries the production document, media representations and credits. A recipient verifies its contents before binding local devices.

Show

An ordered rundown names a set and its segments. Starting a segment gives that occurrence its own transport and cue history.

Segment

An editorial unit such as an interview or a sponsor break. It selects a sequence and an opening layout for each orientation.

Sequence

The timeline places cuts, audio, automation and cues in exact rational time. A seek evaluates that instant without broadcasting earlier cues.

Set and layouts

The set owns reusable compositions and input requirements. Here one segment switches between desk and insert layouts. Other segments can reuse either.

Render graph

Each layout selects an output graph. The desk composites its layers. The insert sends its layers through a fragment shader. The device prepares the rendering resources.

What travels with the show

Robin’s microphone is required in the live layout. Robin can turn the camera off. The score includes eight editable notes and a rendered stem. The picture cue stays at sample 96,000 when the score changes from 120 to 96 BPM.

# Producer creator library

Reset recovery snapshot: 2026-11-03. Seven importable Sets and the complete original sound collection.

## Restore

1. Clone or download this repository.
2. Import each `.set.json` in `sets/` using Producer Set import. Artwork and headshots are embedded in the packages. Camera slots must be assigned on the new computer; provider integrations and transcription require your own connections and credentials.
3. Copy `sounds/Myinstants-US-Top-250` to your Music/Producer/Sounds folder. In a Producer room, open Sounds and import that folder. There are 250 MP3 files, representing 245 distinct audio contents; duplicate detection is expected.
4. Install the Stream Deck app and the Producer Sounds plugin from `streamdeck/`. Pair it again with Producer on the new computer. See `streamdeck/SETUP.txt`.

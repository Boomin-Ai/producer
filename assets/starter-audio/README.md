# Producer audio library

Owned by Boomin. Includes the complete 250-entry sound collection (245 distinct recordings) plus IN CASE waiting music and five curated Set cues.

The manifest retains asset IDs, names, byte lengths and SHA-256 checksums. Curated cues include their source and intended use. Classic uses Whoosh Wind when switching to Solo. The Price Is Right Winner is available for winner reveals and other deliberate button cues. Audio is bundled offline on all desktop platforms. Native installation is additive, keeps music separate from sound effects, and does not connect effects to individual rooms or start playback.

# Producer 0.4.89

Connect Threads in Producer, create and publish text posts from Manager, and bring your account into a dashboard Set. Channel metrics, a post spotlight and live replies share the same Set; choose the spotlight post in the Set editor’s data panel.

Boomin Network connections and messaging help workspaces coordinate shows. Request a Producer-to-Producer appearance using your room and Set as the guest feed, with existing room access checks and host admission.

Guest seats show return-audio playback status and retry controls. Expand the host’s program preview without replacing its stream. Room-reopen recovery restores guest connections and retries Set output when its bound source becomes ready.

First-run setup opens directly to a silent welcome, followed by permissions and sign-in. New beta users need a Boomin account and workspace; existing connected servers remain available. Public network listing is optional and off by default.

Producer 0.4.88 remains the separately published manual Windows patch. This release does not alter its installers or release policy.

Boomin Network remains in beta. Native live production is supported on Apple Silicon Mac and Windows; Intel Mac and Linux retain their existing engine-less builds. Threads access depends on the permissions Meta has approved for the connected account.

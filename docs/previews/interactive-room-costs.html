Assumptions and sources

All remote people subscribe to program video. Each stage camera sends 1.2 Mbps to Producer; stage microphones are 32 kbps. Viewers receive 96 kbps full mixed audio. Stage guests receive a 64 kbps host/media bus and other guests' microphones, excluding their own. One host, no extra screen shares or backstage feeds. Decimal GB/hour = aggregate Mbps × 0.45. Interactive host upload includes the full audio track and, when stage guests exist, the host/media bus. Direct RTMP outputs each use the current 4.5 Mbps video + 160 kbps audio profile.

Cloudflare SFU pricing: $0.05/GB egress; account-wide 1,000 GB/month shared with TURN, excluded from this estimate. Stream pricing: $1/1,000 delivery minutes; WebRTC billing starts October 15, 2026. RealtimeKit pricing: $0.002 per audio/video participant-minute. Bitrates do not guarantee picture quality.

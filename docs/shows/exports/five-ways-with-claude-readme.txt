5 WAYS TO MAKE MONEY WITH CLAUDE

Import five-ways-with-claude-dual-format.show.json using Set settings → Import JSON.
Assign Host camera to your camera. Send the set to output.
Choose Output settings → Both. In Portrait composition choose the matching portrait layout.
Seven segments have fourteen total layouts: opening, websites, content, research, automation, digital products, and next step. Each pair shares content fields and the host source slot.

Current limitation: Next advances the assigned landscape layout. Select the corresponding portrait layout manually in Output settings. Segment-to-both-output automatic mapping is not implemented in the current JSON contract.

RECORDING TODAY
Record records the main landscape canvas only, even when Both is selected in the workspace. Portrait is not included in that file and a second portrait recording is not started.

DUAL RECORDING DESIGN
Separate landscape and portrait files, each with its own video encoder and canvas binding. Both use the same room audio mix and share start/stop timing. The 15-second isolated native proof validated simultaneous files, but the room Record button is not wired to do this yet.

CONTENT
Five offer ideas, not income guarantees: business websites, content packages, research briefs, workflow tools, and digital products. Use your own expertise, review deliverables, and validate demand with a paid pilot.

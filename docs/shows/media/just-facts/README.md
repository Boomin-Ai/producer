# just-facts generated layers

Generated through the built-in imagegen tool for the fresh module-based library, 2026-10-24.

- `studio-landscape.png`: frontal 16:9 cinematic studio plate, uncluttered central negative space, no baked text/cameras/UI.
- `studio-portrait.png`: independently recomposed 9:16 variant using the landscape plate as an image reference; same architectural/material identity.
- `camera-bezel.png`: front-on 16:9 foreground rim, real transparent center/exterior, no glass across opening. Native camera placement belongs under this image, live text above it.

Art direction: Ink-blue research newsroom, bone limestone and fluted glass, cobalt-white accents.

These assets are layers, not a completed runnable set. Live source roles, answer/poll/message typography, data, motion and weather effects must be authored separately. Original generations remain in the Codex generated-images directory; selected assets are copied here. No cutout was recreated through code or a raster editor. The shared [asset manifest](../../../set-runtime/generated-asset-manifest.json) records dimensions, transparency and measured center-line opening bounds for native source alignment.

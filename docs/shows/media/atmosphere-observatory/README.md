# Atmosphere observatory artwork

Generated with the built-in image generation tool. Runtime camera sources, city names, forecasts, typography and controls are separate native/composited layers. The landscape artwork uses a center crop for portrait. The scene represents a generic observatory, not the selected city's skyline.

- `observatory-day.png`: daylight architectural backdrop.
- `observatory-night.png`: matching night variant.

Prompt set:

1. Create a premium open-sky rooftop weather observatory, landscape 16:9. Elegant graphite canopy with narrow champagne brass light seams, honed reflective stone floor, enormous pale blue sky with gentle clouds, distant generic mountains and lake, sunrise warmth. Spacious, photoreal, restrained luxury. Compose for a usable center portrait crop. No recognizable city skyline: location changes at runtime. No people, text, logos, numbers, UI, screens, camera frames or baked-in weather information.
2. Edit the same architecture into its night variant. Preserve the exact camera framing, geometry and materials. Deep blue night sky with faint stars, cool ambient illumination and warm architectural reflections. No sun or moon, no text, UI or people. Camera, forecasts and weather effects will be composited at runtime.

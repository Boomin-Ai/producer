# Producer v0.4.72

Based on production v0.4.71, adds the signed portrait-camera pair, native whole-picture virtual-camera mirroring, and portrait set fallback. The mirror preference persists and updates the live camera without restarting it. Matching portrait set layouts stay preferred; landscape-only sets are fitted rather than replaced by room-camera sources. Producer output cameras are excluded from camera input selection to prevent feedback.

The macOS camera plugin and portrait extension are rebuilt from pinned OBS source during release, then signed and notarized with the assembled app. The normal updater remains enabled. The dev isolation feature and synthetic probe are not enabled in production.

Existing platform capabilities remain: Apple Silicon native LiveKit hosting, Windows Live engine, engine-less Intel macOS and Linux. The macOS virtual-camera additions do not add Windows or Linux camera support. Published through [release run 39127778689](https://github.com/Boomin-Ai/producer/actions/runs/39127778689), all four platform jobs successful. Public producer.dev downloads match v0.4.72 for all platforms after the edge listing cache refreshed. The production updater manifest includes matching verified signatures for Apple Silicon, Intel Mac, Windows and Linux. The downloaded Apple Silicon app passes deep/strict codesign, Gatekeeper, camera bundle checks and notarization ticket validation; its DMG ticket also validates. Windows installers retain the existing lack of publisher code signing; their updater signatures verify. Real live mirror-frame capture remains unverified beyond pixel and browser checks.
